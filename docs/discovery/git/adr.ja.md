# ADR: Gitによる関係探索

## 状態

採用。移動先探索は評価が必要な初期実装とする。

## 決定

存在する追跡対象は現在のパスのGit履歴から共変更の証拠を集める。`--follow`を指定すると主探索とテスト探索でGitの名前変更履歴をたどる。既定では無効とする。コミットメッセージと変更パスは確認可能な手掛かりであり、関係を確定しない。メッセージの取得に失敗した場合はその証拠を空にし、差分の取得に失敗したコミットは飛ばす。

作業ツリーにない入力は、直近の過去の内容を取得して、現在の追跡対象のコードと文書を比較する。ファイル名の一致、内容の完全一致、Ctagsの共通定義をそれぞれ移動先の手掛かりとして記録し、複数の候補を残す。定義の比較は同じ拡張子のコードに限る。Ctagsがなければ警告する。一致がなくても削除されたとは断定せず、過去の内容を取得できる必要がある。結果は移動先候補であり、共変更履歴ではない。tree-sitterの将来の利用は評価する。

## 制約

通常の履歴探索は以前の名前をたどらない。Ctagsは定義を見逃したり無関係の同名定義を照合したりする。照合は追跡対象に限られ、すべての移動や分割を見つけられるわけではない。現段階ではGitの実行が必要である。追跡モードはGit CLIを使い、定義の一致によって移動が確定するわけではない。順位付けとスコア付けは探索と分ける。
