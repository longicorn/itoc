# 出力のプロダクト要件

## 目的

出力は準備済みの候補を、人や後続のツールが利用できる形式に整える。候補の探索、スコア付け、フィルタリングは行わない。

## 要件

- 候補をテキストとJSON形式で提示する。
- テキストでは候補を実装、テスト、文書に分け、要求に応じて詳細な根拠を示す。
- 後続のツールが利用できるよう、JSONに候補の各項目を含める。
- 候補が見つからなかったことを伝える。

[CLI](../cli/prd.ja.md)が形式を選び結果を書き出し、[フィルター](../filter/prd.ja.md)が候補集合を整え、[分析](../analysis/prd.ja.md)が候補の項目と根拠を定める。候補は手がかりであり、関係の証明ではない。

## 現在の動作

`renderCandidates`はテキストまたはJSON形式を選ぶ。テキスト出力はimplementation、test、documentの見出しで候補を分ける。共変更commit IDや文書参照などの詳細な根拠は既定で隠し、`--verbose`を指定すると表示する。候補が空の場合はコード候補が見つからなかったことを表示する。

JSON出力は候補レコードの配列で、path、score、共変更commit数、filename bonus、kind、noise score、任意のnoise termを含む。テストらしい候補のkindは`test`となる。CLIは整形済みのバイト列を標準出力に書く。ファイルへの出力は未実装である。
