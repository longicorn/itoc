# フィルターのプロダクト要件

## 目的

フィルターは探索された候補を表示用に整え、利用者が作業に関連する候補に絞り込めるようにする。

## 要件

- 拡張子とパスで候補を選択し、個別の候補やグループを除外できる。
- ノイズのしきい値と候補の最低スコアを変更できる。
- 候補を順位付けし、グループごとの件数制限を設定できる。

候補のスコアと分類は[分析](../analysis/prd.ja.md)、オプションは[CLI](../cli/prd.ja.md)、表示は[出力](../output/prd.ja.md)で定義する。

## 現在の動作

`prepareCandidates`は拡張子とパスによるフィルター、候補とグループの除外、ノイズのしきい値、最低スコア、並べ替え、グループごとの件数制限を適用する。既定ではノイズスコアが1を超える候補を隠す。`--max-noise-score`でしきい値を変更でき、`--show-noisy`ですべての候補を含められる。件数制限が0の場合は無制限となる。

通常のパスフィルターはリポジトリ相対パスの部分文字列に一致する。globのメタ文字を含むパターンはGoの`filepath.Match`構文でパス全体に照合し、`*`は`/`をまたがない。拡張子フィルターは小文字化した拡張子を比較する。`--exclude-candidate`にはグループ名または完全一致するリポジトリ相対の候補パスを指定する。
